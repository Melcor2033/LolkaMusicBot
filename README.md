Бот для платформы [Lolka](https://lolka.app) с системой динамических приватных голосовых каналов и музыкальными плеерами. Поддерживает Яндекс.Музыку, VK Музыку, RuTube, Lofi Radio и Spotify/YouTube.

---

## Функционал

### Динамические голосовые каналы

- Пользователь заходит в «Мастер-канал» — бот мгновенно создаёт для него персональную комнату и перемещает туда.
- Когда все покидают комнату, она автоматически удаляется.
- Поддерживается неограниченное количество мастер-каналов на одном сервере.
- Владелец комнаты получает панель управления прямо в Lolka:
  - переименование канала;
  - установка лимита участников;
  - закрытие/открытие канала для посторонних.
- При выходе владельца права передаются одному из оставшихся участников.
- Административная панель настройки (`/setup`) для управления мастер-каналами.

### Музыкальные плееры

- **Яндекс.Музыка** — персональная «Моя Волна», очереди воспроизведения, кэширование треков. OAuth-токены пользователей хранятся в базе данных в зашифрованном виде.
- **VK Музыка** — воспроизведение треков и плейлистов через VK (настраивается через `VK_COOKIE` и `VK_USER_TOKEN`).
- **Lofi Radio** — встроенный радиоприёмник с выбором станций и поддержкой пользовательских потоков.
- **RuTube** — воспроизведение видео и аудио с RuTube, режим 24/7.
- **Dynamic Музыка (YouTube и Spotify)** — парсинг плейлистов Spotify, стриминг с YouTube. Поддерживает работу через прокси для обхода гео-блокировок.

- Для всех плееров сохраняется индивидуальный уровень громкости в PostgreSQL и восстанавливается при перезапуске.
- Режим 24/7 — бот подключается к голосовому каналу автоматически при старте.

## Технологический стек

| Компонент | Технология |
|-----------|-----------|
| Язык | Python 3.12+ |
| Discord API | `lolka.py` v2.7+ (форк `discord.py`) |
| База данных | PostgreSQL 15 (SQLAlchemy + asyncpg) |
| Миграции | Alembic |
| Аудио | FFmpeg, PyAV, aiortc (WebRTC) |
| Контейнеризация | Docker, Docker Compose |

## Архитектура

```
src/
  bot.py              — Точка входа, инициализация бота, монкипатчи
  config.py           — Загрузка конфигурации из переменных окружения
  db.py               — Модели SQLAlchemy, функции работы с БД
  lofi_streams.py     — Реестр Lofi-станций
  partners.py         — Конфигурация партнёров и спонсоров
  cogs/
    voice.py          — Управление динамическими каналами
    yandex_music.py   — Стриминг Яндекс.Музыки
    lofi.py           — Стриминг Lofi Radio
    rutube.py         — Стриминг RuTube
    spotify.py        — Стриминг Spotify/YouTube
  views/              — UI-компоненты (discord.ui кнопки, панели, меню)
  patches/
    _voice_impl.py    — Патч WebRTC-слоя: устранение утечек памяти

xray/                 — Конфигурация Xray-прокси (для обхода блокировок)
tests/                — Юнит-тесты (pytest)
```

## Быстрый старт через Docker

### 1. Клонирование репозитория

```bash
git clone https://github.com/ВашПрофиль/DynamicVoiceBot.git
cd DynamicVoiceBot
```

### 2. Настройка переменных окружения

```bash
cp .env.example .env
```

Откройте `.env` и заполните переменные. Минимально необходимые:

```ini
DISCORD_TOKEN=ваш_токен_бота
```

Остальные переменные описаны в разделе ниже.

### 3. Запуск

```bash
docker compose up -d --build
```

При первом запуске бот автоматически применит миграции базы данных (`alembic upgrade head`) и подключится к Discord.

Для запуска с прокси-контейнером Xray (для обхода блокировок Spotify/YouTube):

```bash
# В .env раскомментируйте строку:
COMPOSE_PROFILES=spotify

# Скопируйте шаблон конфига Xray и заполните своими данными:
cp xray/config.example.json xray/config.json

docker compose --profile spotify up -d --build
```

### 4. Локальный запуск без Docker

```bash
python -m venv .venv
.venv\Scripts\activate       # Windows
# или
source .venv/bin/activate    # Linux/macOS

pip install -r requirements.txt

# Применить миграции (PostgreSQL должен быть запущен):
alembic upgrade head

python src/bot.py
```

## Переменные окружения

### Основные настройки

| Переменная | Описание | Обязательно |
|------------|----------|-------------|
| `DISCORD_TOKEN` | Токен бота из [Портала разработчика Lolka](https://lolka.app/developers/portal) | Да |
| `DATABASE_URL` | Строка подключения к PostgreSQL. При запуске через Docker Compose менять не нужно. | Да |
| `LOG_LEVEL` | Уровень логирования: `DEBUG`, `INFO`, `WARNING`, `ERROR`. По умолчанию `INFO`. | Нет |
| `DEFAULT_BOT_NICKNAME` | Имя бота при входе на сервер. По умолчанию `Dynamic Voice`. | Нет |
| `DISCORD_LOG_WEBHOOK_URL` | Webhook URL для отправки критических ошибок в канал Lolka. | Нет |

### Музыкальные модули (Feature Flags)

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `ENABLE_YANDEX_MUSIC` | Включить модуль Яндекс.Музыки. | `false` |
| `YM_ENCRYPTION_KEY` | Ключ шифрования OAuth-токенов пользователей. Обязателен если `ENABLE_YANDEX_MUSIC=true`. Генерация: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` | — |
| `ENABLE_BLEND` | Включить совместные рекомендации в «Моей Волне». | `true` |
| `ENABLE_RUTUBE_MUSIC` | Включить модуль RuTube. | `true` |
| `ENABLE_LOFI_RADIO` | Включить модуль Lofi Radio. | `false` |
| `ENABLE_SPOTIFY` | Включить модуль Spotify/YouTube. | `false` |

### Прокси и обход блокировок

| Переменная | Описание | Пример |
|------------|----------|--------|
| `COMPOSE_PROFILES` | Установите `spotify` для запуска контейнера Xray. | `spotify` |
| `YTDLP_PROXY` | Прокси для yt-dlp (скачивание и метаданные). | `http://xray:10809` |
| `SPOTIFY_PROXY` | Прокси для обращений к Spotify. | `http://xray:10809` |
| `STREAM_PROXY` | Прокси для аудио-стриминга. | `http://xray:10809` |
| `SPOTIFY_SEARCH_PROVIDERS` | Провайдеры поиска треков. | `youtube,soundcloud` |

### Прочее

| Переменная | Описание |
|------------|----------|
| `DONATION_BOOSTY_URL` | Ссылка на Boosty для кнопок поддержки в UI (опционально). |
| `DONATION_ALERTS_URL` | Ссылка на DonationAlerts (опционально). |
| `SPOTIFY_CLIENT_ID` / `SPOTIFY_CLIENT_SECRET` | Данные приложения Spotify (опционально). |

## Настройка в Lolka

После запуска бота выполните следующие шаги на вашем сервере:

1. Зарегистрируйте бота в [Портале разработчика Lolka](https://lolka.app/developers/portal) и получите токен.

2. Пригласите бота на сервер. Минимально необходимые права:
   - Просматривать каналы
   - Управлять каналами
   - Управлять ролями
   - Отправлять сообщения
   - Встраивать ссылки
   - Перемещать участников

3. Создайте категорию для временных комнат (например, «Приватные»).

4. Создайте голосовой канал-триггер внутри этой категории (например, «Создать комнату»).

5. Выполните команду `/setup` (доступна только администраторам).

6. В панели нажмите «Добавить мастер», выберите созданный канал и категорию, сохраните.

Теперь любой пользователь, зашедший в мастер-канал, получит персональную комнату.

### Основные команды

| Команда | Описание |
|---------|----------|
| `/setup` | Открыть административную панель настройки (только для администраторов) |
| `/help` | Интерактивная справка по возможностям бота |
| `/voice_panel` | Отправить панель управления комнатой в текущий канал |
| `/music_panel` | Главное меню выбора музыкального плеера |
| `/ym play [запрос]` | Поиск и воспроизведение трека в Яндекс.Музыке |
| `/ym wave` | Включить «Мою Волну» в Яндекс.Музыке |
| `/dynamic [ссылка]` | Воспроизвести трек или плейлист из Spotify/YouTube |
| `/rutube [ссылка]` | Воспроизвести видео с RuTube |
| `/volume [1-100]` | Изменить уровень громкости активного плеера |
